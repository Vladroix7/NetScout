================================================================================
                        NETSCOUT — WHAT IS THIS PROJECT?
================================================================================

OVERVIEW
--------
NetScout is a Network Security Monitoring Tool.
It lets a regular user scan their local network (find devices, open ports, OS)
and an admin manage all users through a separate admin panel.

The project has TWO separate Windows desktop applications:
  - NetScoutClient  → what the user sees and uses (login, scan network)
  - NetScoutServer  → what the admin runs (see users, manage accounts)

Both talk to each other over TCP on port 11111.
Both use one shared MySQL database (netscout).

================================================================================
                              DATABASE TABLES (6)
================================================================================

Users
  - Id, Email, Password (SHA-256 hash), Username, IsAdmin, CreatedDate, LastLogin

ScanResults
  - Id, UserId, TargetRange, ScanType, DeviceCount, ScanDate

Devices
  - Id, ScanResultId, IPAddress, MACAddress, Hostname, OS, ResponseTime

OpenPorts
  - Id, DeviceId, PortNumber, Protocol, ServiceName, Status

SecurityIssues
  - Id, DeviceId, IssueType, Description, Severity (Low/Medium/High/Critical)

Settings
  - Id, Key, Value


================================================================================
                              WHO DOES WHAT
================================================================================

ADMIN (NetScoutServer):
  - Logs in with admin credentials
  - Sees all registered users
  - Can delete users (but NOT admin@netscout.com)
  - Can make/remove admin status
  - Can change any user's password
  - Sees who is currently logged in (real-time)
  - Sees all server events in a log panel
  - Gets notified when a user asks to reset their password

USER (NetScoutClient):
  - Registers / Logs in
  - Scans the network using 4 scan types:
      1. Ping Scan      — finds who is alive on the network
      2. Port Scan      — checks what ports/services are open
      3. OS Detection   — guesses what OS each device runs
      4. Aggressive     — all of the above combined
  - Can request a password reset from the admin
